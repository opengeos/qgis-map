# Installation

## Stable release

Use `pip` to install:

```bash
pip install qgis-map
```

Or use `conda` to install:

```bash
conda install -c conda-forge qgis-map
```

## From sources

To install qgis-map from sources, run this command in your terminal:

```bash
pip install git+https://github.com/opengeos/qgis-map
```
